# yegoshua/tap

Homebrew casks for [Notch Orchestrator](https://github.com/yegoshua/notch-orchestrator).

```sh
brew install --cask yegoshua/tap/notch-orchestrator
```

The app is not notarized by Apple; the cask removes the quarantine mark Homebrew puts on it, so
that macOS opens it. The [one-line installer](https://github.com/yegoshua/notch-orchestrator#install) is the primary way to install.
