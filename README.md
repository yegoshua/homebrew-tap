# yegoshua/tap

Homebrew casks for [Notch Orchestrator](https://github.com/yegoshua/notch-orchestrator).

```sh
brew install --cask --no-quarantine yegoshua/tap/notch-orchestrator
```

The app is not notarized by Apple, so without `--no-quarantine` macOS refuses to open it. The
[one-line installer](https://github.com/yegoshua/notch-orchestrator#install) is the primary way to install.
